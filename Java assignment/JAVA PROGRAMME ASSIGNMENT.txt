Q18. Write a Java program to find the largest and smallest elements in an array.

import java.util.Scanner;

class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter the number of elements: ");
        int n = sc.nextInt();

        if (n <= 0) {
            System.out.println("Please enter a positive number.");
            return;
        }

        int[] numbers = new int[n];

        System.out.println("Enter " + n + " numbers:");

        for (int i = 0; i < n; i++) {
            numbers[i] = sc.nextInt();
        }

        int largest = numbers[0];
        int smallest = numbers[0];

        for (int i = 1; i < n; i++) {
            if (numbers[i] > largest) {
                largest = numbers[i];
            }

            if (numbers[i] < smallest) {
                smallest = numbers[i];
            }
        }

        System.out.println("Largest = " + largest);
        System.out.println("Smallest = " + smallest);
    }
}

Enter 5 numbers:

4
25
7
9

Q19. Write a Java program using an abstract class with at least three child classes.

abstract class Vehicle {
    String brand;

    Vehicle(String brand) {
        this.brand = brand;
    }

    void start() {
        System.out.println(brand + " is starting.");
    }

    abstract void move();
}

class Car extends Vehicle {
    Car(String brand) {
        super(brand);
    }

    void move() {
        System.out.println(brand + " is moving on the road.");
    }
}

class Bicycle extends Vehicle {
    Bicycle(String brand) {
        super(brand);
    }

    void move() {
        System.out.println(brand + " is moving by pedaling.");
    }
}

class Boat extends Vehicle {
    Boat(String brand) {
        super(brand);
    }

    void move() {
        System.out.println(brand + " is moving on water.");
    }
}

class Main {
    public static void main(String[] args) {

        Vehicle[] vehicles = {
            new Car("Toyota"),
            new Bicycle("Hero"),
            new Boat("Sea Boat")
        };

        for (Vehicle v : vehicles) {
            v.start();
            v.move();
            System.out.println();
        }
    }
}

OUTPUT:

Toyota is starting.
Toyota is moving on the road.

Hero is starting.
Hero is moving by pedaling.

Sea Boat is starting.
Sea Boat is moving on water.

class Fan implements Switchable {

SECTION 6: INNER CLASS, STATIC NESTED CLASS & ANONYMOUS INNER CLASS

Q21. Write a Java program to demonstrate Inner Class, Static Nested Class and Anonymous Inner Class

interface Notifier {
    void sendMessage();
}

class BankAccount {
    private double balance;

    BankAccount(double balance) {
        this.balance = balance;
    }

    // Inner Class
    class AccountManager {
        void showAndAddMoney(double amount) {
            System.out.println("Old Balance = " + balance);

            balance = balance + amount;

            System.out.println("Updated Balance = " + balance);
        }
    }

    // Static Nested Class
    static class Receipt {
        void printReceipt() {
            System.out.println("Receipt printed successfully.");
        }
    }

    void notifyCustomer(Notifier notifier) {
        notifier.sendMessage();
    }
}

class Main {
    public static void main(String[] args) {

        BankAccount account = new BankAccount(5000.0);

        // Creating Inner Class object
        BankAccount.AccountManager manager =
                account.new AccountManager();

        manager.showAndAddMoney(1500.0);

        // Creating Static Nested Class object
        BankAccount.Receipt receipt =
                new BankAccount.Receipt();

        receipt.printReceipt();

        // Anonymous Inner Class
        Notifier message = new Notifier() {
            public void sendMessage() {
                System.out.println("Customer notified successfully.");
            }
        };

        account.notifyCustomer(message);
    }
}

OUTPUT:

Old Balance = 5000.0
Updated Balance = 6500.0
Receipt printed successfully.
Customer notified successfully.
